# HR Employee Attrition Analysis

> EDA on IBM HR data to identify key drivers of employee attrition (department, overtime, tenure), visualized in an interactive Power BI dashboard.

## Objective
Identify the factors most associated with employee attrition to inform HR retention strategy.

## Dataset
[IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) (Kaggle)

## Tools
Python (Pandas, Seaborn), Power BI, Google Colab

## Process
1. Explored attrition patterns by department, overtime, income, and tenure
2. Engineered age/tenure buckets and an attrition flag for dashboarding
3. Built a Power BI dashboard summarizing attrition rate and key drivers
